GameVault · pacman repo

Modern personal game library manager, playtime tracker, and launcher.

Install

# 1. append the repo to pacman.conf
echo -e '\n[gamevault]\nServer = https://itzsornet.github.io/Gamevault/x86_64\nSigLevel = Optional TrustAll' | sudo tee -a /etc/pacman.conf

# 2. sync and install
sudo pacman -Syu
sudo pacman -S gamevault
Run pacman -Syu, not -Sy alone — a partial upgrade on Arch is unsupported. Uninstall with sudo pacman -Rns gamevault.
